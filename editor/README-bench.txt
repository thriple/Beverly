Beverly bench - measures your graphics card and processor

Run beverly-bench.exe and leave it alone. A small window shows which test it is on. It tries lots of polygons, lights
with and without shadows, moving headlights, crowds of agents on the processor, and how much video memory holds,
at 1080p and again at 4K. The whole run takes a few minutes.

When it finishes (or if it stops or crashes part way) there is a file beside the program: beverly-bench-log.txt.
Send that file back. It lists your graphics card, processor and memory and the results; it holds no names, paths or
anything else of yours, and nothing is sent anywhere by the program.

Close other programs first for a fair result. If the screen goes black for a moment during the video memory test, that
is expected; the log shows how far it got.

beverly-bench.exe --quick  runs only the lightest steps (to check it starts).
